# 视频标注弹窗功能实现计划

实现一个 1:1 还原的“标注视频帧”功能，允许用户在 Creative Assistant 页面点击视频上方的标注按钮后，弹出一个全屏/半全屏的标注编辑器。用户可以对当前视频画面进行修改（画笔、文字、选区等），确认后将该帧作为图片资源自动填充到输入框中。

## 用户界面 (UI) 修改

- **标注编辑器弹窗 (`VideoAnnotationDialog.tsx`)**:
  - 创建一个新的弹窗组件，背景为半透明磨砂或纯白/纯黑（适配主题）。
  - **顶部工具栏**: 包含矩形选区、画笔、箭头、文字、橡皮擦、定位、圆角矩形、重点标注（红色圆点）、撤销、重做等图标。
  - **中间画布区**: 显示视频当前帧，支持在图片上进行矢量或位图标注。
  - **底部控制栏**: 视频播放进度条、播放/暂停按钮、当前时间/总时间。
  - **右下角操作按钮**: “取消”和“确认”。
- **Creative Assistant 页面 (`src/routes/creative-assistant.tsx`)**:
  - 为视频悬浮工具栏中的“标注视频帧”图标添加点击事件，触发弹窗打开。
  - 传递当前视频的 URL 和当前播放时间点给弹窗。

## 技术细节

- **画布库**: 使用 `framer-motion` 处理弹窗动画。标注功能可先实现 UI 框架，核心交互使用 Lucide 图标。
- **状态管理**: 
  - 在 `CreativeAssistantPage` 中添加 `isAnnotationOpen` 状态。
  - 记录触发标注时的视频时间戳，以便截取该帧（模拟）。
- **资源回调**: 点击“确认”时，将当前画面（模拟为 `saitamaAsset.url` 或其他图片资源）通过 `window.dispatchEvent` 或直接回调发送到 `PromptBox` 的 `attachments` 中。

## 开发步骤

1. **新建组件**: 在 `src/components/` 下创建 `VideoAnnotationDialog.tsx`。
2. **样式适配**: 使用 Tailwind CSS 确保弹窗在亮色/暗色模式下的视觉表现一致。
3. **逻辑触发**: 在 `src/routes/creative-assistant.tsx` 中引入并使用该弹窗，完善点击“标注视频帧”后的交互。
4. **集成输入框**: 实现点击确认后，将图片引用自动填充到页面底部的输入框中。
